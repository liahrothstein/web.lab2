# 🎓 Лабораторная работа №2 — Веб-технологии

Проект представляет собой личную страницу студента, реализованную на **React** с использованием архитектурной методологии **FSD (Feature-Sliced Design)**. Основная цель работы — освоение табличной верстки в современном React-приложении, работа с **SCSS** и динамическое отображение данных.

## 🛠 Стек технологий

- **Frontend:** React 18 + Vite
- **Язык:** TypeScript
- **Стилизация:** SCSS (Sass)
- **Архитектура:** Feature-Sliced Design (FSD)

## 🏗 Структура проекта (FSD)

- `src/app` — Инициализация приложения (стили, провайдеры).
- `src/pages` — Страницы приложения (Главная, Факультет, Группа, Расписание).
- `src/widgets` — Крупные блоки страниц (Header, Nav, Main, Footer).
- `src/shared` — Переиспользуемые ресурсы (UI-кит, константы, стили, ассеты).

## 📋 Реализованный функционал

### 🖼 Табличная верстка (Layout)

Весь каркас приложения построен на `<table>`. Реализована сложная система разделителей с использованием переменных:

- **Вертикальные линии:** 1px (thin) и 3px (thick).
- **Горизонтальные разделители:** Акцентные линии черного цвета между секциями.

### 📅 Расписание занятий

Реализовано динамическое расписание с вложенными таблицами:

- Отображение дней недели, времени и предметов.
- Сложная логика объединения ячеек для пар с несколькими подгруппами.

### 👥 Список группы

- Вывод списка студентов подгрупп (КФ-17).
- Двухколоночная верстка списков с использованием **Flexbox** внутри табличных ячеек.

### 📝 Зачеты и экзамены

- Разделение на два блока: Зачеты и Экзамены.
- Вывод названия предмета и ФИО преподавателя.

## 🎨 Стилизация

В проекте активно используются **SCSS Variables** для централизованного управления дизайном:

- `$line-color`: Основной цвет линий (черный).
- `$line-thin` / `$line-thick`: Толщина разделителей.
- Использование **CSS Modules** для предотвращения конфликтов стилей.
